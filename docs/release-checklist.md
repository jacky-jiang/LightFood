# Release Checklist

- [ ] Apple Developer Program account is active.
- [ ] Bundle Identifier is correct.
- [ ] App icon is complete.
- [ ] Launch screen is configured.
- [ ] Signing & Capabilities are correct.
- [ ] Version and build number are updated.
- [ ] Privacy information is complete.
- [ ] Tests pass locally.
- [ ] CI passes on main.
- [ ] Archive is created successfully.
- [ ] TestFlight release notes are prepared.
- [ ] App Store review information is complete.
